**Every-Remainder-Everywhere**

A Lean 4 formalization of a mathematical result concerning the inverse tree of the Collatz map.

The project investigates whether, for a fixed positive integer (v) not divisible by (3), the positive integers that eventually reach (v) under the Collatz map occur infinitely often in every residue class modulo each prime.

The repository contains the Lean source code, a mathematical account of the result (*surjectivity of the predecessor tree modulo every prime...*) and research notes.
